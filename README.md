# Quiz CLI

An interactive command-line quiz game for learning JavaScript.

## Overview

Quiz CLI is a Node.js CLI application built with ES modules. It loads quiz questions from a local JSON file, guides the user through category and question selection, and displays results at the end of each round.

## Requirements

- Node.js 18 or newer

## Scripts

- `npm start` — run the quiz app
- `npm test` — run the test suite using Node's built-in test runner

## Project structure

Based on the repository layout, the application is expected to use these key files:

- `index.js` — main entry point
- `src/input.js` — terminal input helpers
- `src/quiz.js` — quiz logic
- `src/colors.js` — terminal color helpers
- `data/questions.json` — quiz question data
